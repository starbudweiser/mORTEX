# Glossaire français de mORTEX

Vocabulaire retenu pour la traduction française (interface héritée de Vortex et textes propres à mORTEX).
macOS d'abord : les termes suivent ceux du système (Réglages, Finder, Dock, ⌘).

| Anglais                               | Français                                   |
| ------------------------------------- | ------------------------------------------ |
| Settings                              | Réglages (Game Settings : Réglages du jeu) |
| Show / Open in Explorer, File Manager | Afficher dans le Finder                    |
| Minimize                              | Placer dans le Dock                        |
| Ctrl+click, Ctrl+A (sélection)        | ⌘-clic, ⌘A                                 |
| staging folder                        | dossier de staging                         |
| deploy / deployment                   | déployer / déploiement                     |
| purge                                 | purger                                     |
| load order                            | ordre de chargement                        |
| endorse                               | recommander                                |
| health check                          | diagnostic                                 |
| curator                               | curateur                                   |
| bundle (a mod)                        | inclure                                    |
| replicate                             | reproduire                                 |
| file override                         | fichier prioritaire                        |
| light / medium plugin                 | plugin léger / moyen                       |
| master, masterlist, userlist          | master, masterlist, userlist (termes LOOT) |
| tweak (INI)                           | réglage INI                                |
| workshop                              | atelier                                    |
| savegame / save game                  | sauvegarde                                 |
| backup                                | copie de sauvegarde                        |
| dashlet                               | widget                                     |
| feedback                              | avis                                       |

Typographie : guillemets « », espace avant « : », « ? », « ! » ; points de suspension « … ».
Le mot « Vortex » des textes source est conservé : mORTEX le remplace à l'affichage.
